# Pharmacy Medicine Demand & Expiry-Risk Forecasting Dataset

## Files
- `daily_medicine_sales.csv`: 10,000 daily product-sales records for 50 synthetic medicines over 200 days.
- `batch_expiry_inventory.csv`: 1,000 synthetic batch-inventory snapshots.

## Suggested use
1. Use `daily_medicine_sales.csv` for product-level demand forecasting.
2. Use `batch_expiry_inventory.csv` for expiry-risk classification.
3. Sort sales records by `product_id` and `date` and use chronological train/validation/test splits.
4. Compare a moving-average baseline with Linear Regression and Random Forest for demand.
5. Compare a transparent rule baseline with Logistic Regression and Random Forest for expiry risk.

## Key columns: daily_medicine_sales.csv
`product_id`, `medicine_name`, `category`, `date`, `units_sold`, `purchase_quantity`,
`stock_on_hand`, `unit_price_inr`, `promotion`, `day_of_week`, `month`, `is_weekend`.

## Key columns: batch_expiry_inventory.csv
`snapshot_date`, `product_id`, `medicine_name`, `category`, `batch_id`,
`batch_quantity_remaining`, `average_daily_sales_30d`, `days_to_expiry`,
`expiry_date`, `unit_price_inr`, `projected_demand_before_expiry`,
`projected_unsold_quantity`, `projected_unsold_ratio`, `expiry_risk`.

## Important methodology note
This is fully synthetic data created for an academic prototype. No real pharmacy,
patient, or personally identifiable information is included.

The `expiry_risk` label is generated by a transparent heuristic:
- High: expiry in 90 days or less AND projected unsold ratio >= 30%.
- Medium: expiry in 180 days or less AND projected unsold ratio >= 15%.
- Low: otherwise.

Because the label is rule-generated from the same underlying risk calculation,
do not claim the classifier has learned real-world expiry outcomes. Clearly
document this limitation and use the model as an advisory demonstration only.
For rigorous evaluation, obtain licensed historical batch outcomes and label
risk based on observed unsold quantities at expiry.

## Reproducibility
Random seed: 42
Sales period: 2026-01-01 through 2026-07-19 (200 days).
Number of products: 50.
